The prompt every model got — unchanged 
Design and create a very creative, elaborate, and detailed voxel art scene of a pagoda
in a beautiful garden with trees, including some cherry blossoms. Make the scene
impressive and varied and use colorful voxels. Use whatever libraries to get this done
but make sure I can just deploy a single HTML file (call it pagoda-<MODEL>.html) on a
static host and open it in Chrome. Do NOT modify or overwrite any existing files in the
repo — only create the new file pagoda-<MODEL>.html.
Figures on this page were measured on 2026-10-19 with the same harness: headless Chromium at 1280×800, seven-second settle (25 s for the NVIDIA page), JS console captured, pixel statistics against the top-left background colour. Older runs were re-measured at the same time, so the numbers are comparable across cards. Runs were made with opencode in headless mode.
